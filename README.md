# 🎯 QR Code Generator

A modern, responsive web application that allows users to generate stylish, customizable QR codes with ease. Designed with beautiful UI/UX patterns, animated backgrounds, glassmorphism design, and responsive layout — it's built for both functionality and visual delight.

![Landing View](https://i.ibb.co/sp9S6j55/image.png)

---

## 🚀 Features

### ✅ QR Code Generation
- Generate QR codes from any URL
- Customize foreground and background colors
- Enable transparent background option
- Select size (100px to 400px)
- Set error correction level (Low, Medium, Quartile, High)

### 🎨 Visual Effects & UX
- Animated background
- Custom cursor effects (disabled on mobile)
- Gradient text, icons & buttons
- Smooth transitions and modern glassmorphism design

### 💾 Download Options
- Export QR Code as PNG
- Supports transparent backgrounds

### 📱 Responsive Design
- Fully mobile-friendly
- Custom cursor auto-disabled on touch devices
